## I think this should be one page

The rework dropped VS Code, Claude Code, and GitHub Desktop entirely. I think
that over-corrected on what I said last week, so let me be clearer about what I
meant.

**The teaching sequence is right.** Day 1 is Claude Desktop only. Students
don't need to see what's happening under the hood, and I don't want them in a
code editor on the first day. Days 2 and 3 move to their own machines, VS Code,
and GitHub. None of that changed.

**The installing sequence is what I'd do differently.** Splitting setup across
two pages means a second round of installs partway through the workshop, and I
don't want to count on that. Whoever skips it shows up to Day 2 not set up and
we lose the morning.

So I'd put everything on one pre-workshop page, in the order they'll use it,
and just label which day each tool is for.

**That said, here's a version of your instinct I think does work.** GitHub
Desktop and VS Code genuinely aren't needed on Day 1. Nothing that day touches
a local repo. So we could leave them on the page but tell students to do those
two at the end of Day 1, or that evening, or first thing Day 2 morning. They're
quick installs, and by then everyone is already working in Claude Desktop and
can ask it for help if something goes wrong.

My instinct is to build the page with all of it in one spot first, and then
decide together what to defer. Easier to move a section down than to remember
it exists on a second page.

## Three things Day 1 actually needs

Day 1 needs exactly these: Claude Desktop, a GitHub account, and Git. That last
one is new information, below.

### Git has to be installed for Day 1, on both platforms

Claude Desktop's Code tab will not open without Git on the machine. Anthropic's
docs are explicit about it in three separate places, including the
troubleshooting section:

> On Windows, Git is required for the Code tab to start local sessions. If you
> see "Git is required," install Git for Windows and restart the app.

For Macs the docs say "most Macs include Git by default," which is not all of
them, so I'd have both platforms check rather than assume. On a Mac, running
`git --version` in Terminal triggers the Xcode Command Line Tools install if
it's missing.

Worth knowing: **GitHub Desktop does not cover this.** It bundles its own copy
of Git but never puts it on the command line, so Claude can't find it. That
surprised me, and it means the Git step is separate from the GitHub Desktop
step even though they look like the same thing.

Source: [code.claude.com/docs/en/desktop](https://code.claude.com/docs/en/desktop),
[desktop#3801](https://github.com/desktop/desktop/issues/3801).

## Smaller corrections

**The app has two tabs now, not three.** The page tells students to confirm
they see Chat, Cowork, and Code. I checked my own machine today and I see
**Home** and **Code**, with New, Artifacts, Routines and Customize in the
sidebar under Home. Chat and Cowork have been merged into Home. Anthropic's
docs still say three tabs, so you were reading the right source and the source
is behind the app. Anyone installing fresh before class will see two and think
they've done something wrong.

**The account details arrive after they install.** The page says to sign in
with your email account, but I'm sending everyone their account details the
week before class. Some of them will download the app before that email lands.
Worth a line saying that's expected, so nobody thinks they're stuck.
