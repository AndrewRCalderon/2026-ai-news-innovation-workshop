Pre-Workshop Setup

Complete this checklist before Day 1:

  • [ ] GitHub account created
  • [ ] Git installed locally
  • [ ] Editor set up (VS Code recommended)
  • [ ] Claude Code / VS Code extension installed and signed in with your workshop enterprise account
  • [ ] Able to run git clone and git push

See the resources page for links, and STUDENT_CLAUDE_GUIDE.md in the repo root for day-specific guidance to paste into your own Claude session.
