Day 1 Setup

Please do this before Day 1 — we won't have time to walk through installs live, and Day 1's hands-on session assumes you're already set up. It should take about 15 minutes. If something doesn't work, don't spend more than that fighting it — stop, note where you got stuck, and we'll sort it out first thing in class.

This page covers Day 1 only. Day 2 introduces a different set of tools (VS Code, Claude Code, Git) — that setup is separate and not needed yet; you'll get that link closer to Day 2.

1. Claude Desktop

The app you'll build with all day — chat, research, and an actual coding environment, all in one place.

2. GitHub Account

GitHub is the website where your work lives online and gets submitted. You just need an account for now — we'll connect it to Claude Desktop together, live, in the first hands-on session.

You don't need to install Git, GitHub Desktop, or anything else for Day 1. Claude Desktop connects to GitHub directly — no separate app, no typed commands.

3. Verify You're Ready

If that works, you're set for Day 1.
