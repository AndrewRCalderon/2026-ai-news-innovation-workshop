Pre-Workshop Setup

Please do this before Day 1 — we won't have time to walk through installs live, and Day 1's hands-on session assumes you're already set up. It's normal for this to take 20–30 minutes. If something doesn't work, don't spend more than that fighting it — stop, note where you got stuck, and we'll sort it out first thing on Day 1.

1. VS Code

Your code editor — this is where you'll write and see code.

  • Download and install VS Code from code.visualstudio.com (it auto-detects your OS).
  • Open it once after installing, just to confirm it launches.

2. Claude Code

The AI coding assistant you'll build with, running inside VS Code.

  • Confirm you have access to the workshop's Claude enterprise account — check your email for an invite. If you don't see one, flag it before Day 1, not on the morning of.
  • In VS Code, open the Extensions panel (the icon that looks like four squares in the left sidebar) and search for "Claude Code." Install it.
  • Sign in with your workshop account when prompted.

3. GitHub

Two different things share this step, worth knowing apart: GitHub is the website where your code lives online. Git is the tool on your computer that tracks changes and sends them there. You need a GitHub account either way — how you install Git depends on whether you're comfortable with a command line.

Create your account first:

  • Sign up for a free account at github.com if you don't already have one.

Then install Git — pick whichever fits you:

  • Not sure, or never used a command line before? Install GitHub Desktop. It's a free app that lets you do everything for this workshop — clone a project, save changes, send them to GitHub — by clicking buttons, with no typed commands at all. This is the recommended option for most people. Sign in with your GitHub account once it's installed.
  • Already comfortable with a terminal? Install Git directly. On Mac, open Terminal (search for it with Spotlight) and type git --version — the first time you do this, it'll prompt you to install Xcode Command Line Tools, which includes Git. On Windows, download it from git-scm.com. GitHub's own step-by-step guide is at docs.github.com if you want more detail than this page gives.
You don't need to memorize Git commands for this workshop. Once Claude Code is set up (see above), you can ask it in plain English to save and submit your work, and it runs the underlying commands for you. This step is just about getting the accounts and apps installed.

4. Opening Claude Code and GitHub Inside VS Code

Once all three are installed, this is how they fit together:

  • Open a project folder in VS Code: File → Open Folder.
  • Claude Code lives in the sidebar — look for its icon, or open the Command Palette (Cmd/Ctrl+Shift+P) and type "Claude Code."
  • Git and GitHub show up in the Source Control panel (the branching-icon in the left sidebar). The first time you interact with a GitHub-hosted repo here, VS Code will prompt you to sign in to GitHub — follow that prompt.

5. Verify You're Ready

  • If you installed GitHub Desktop: open it and confirm you're signed in to your GitHub account.
  • If you installed Git directly: open Terminal and run git --version — it should print a version number, not an error.
  • Either way: open Claude Code once and confirm it opens without an error and shows you're signed in.
If that works, you're set for Day 1.
