Skills & Best Practices

Package your expertise so it doesn't need re-explaining.

11:40 AM·40 MIN·Lecture
01

What a Skill Is

A reusable, filesystem-based resource: a folder of instructions, scripts, and reference material, organized roughly like an onboarding guide.

A prompt is conversation-level, for one task. A Skill loads on demand. A 14-skill journalism collection (AP style, source verification, FOIA templates) already exists, free to install.

02

What Actually Makes This Work

The Claude Code team's own account of building skills for production, sharper than the general advice.

  • Build the Gotchas section from failures you actually watched happen. It's the highest-signal part, and an imagined failure guards against a problem that was never real.
  • Run the task once without the skill first. Skip that, and you have no baseline, so you can't tell what actually changed.
  • If Claude doesn't reach for a skill reliably, the problem is usually the description. Vague ones kill routing, write one specific enough to say exactly when to use it.
03

Build One

Five steps, from noticing you need one to actually trusting it.

  1. 1

    Notice the pattern

    Same test as CLAUDE.md. Explained twice, or corrected twice.

  2. 2

    Create the folder and file

    Its own folder, named after the skill, one required SKILL.md inside.

  3. 3

    Fill it in like an onboarding doc

    A description of what and when, then instructions like briefing a new hire.

  4. 4

    Test it two ways

    Ask a matching question, then invoke it directly by name.

  5. 5

    Stress-test it honestly

    Real examples, not abstract rules. Then a fresh conversation, messy input.

04

Common Failure Patterns

The confident-looking failure
Passes your test cases, fails on real input, a missing field, an edge case you didn't write down. Fix: write real examples, test in a fresh conversation with messy input.
The patch spiral
One-line fixes pile into contradictions. Fix: rebuild from what failed. Can't explain why each rule is there? Time to rebuild.
Installing skills from strangers
Shared skill repos have shipped credential-stealing malware. Fix: read before installing.
