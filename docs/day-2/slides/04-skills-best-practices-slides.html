Skills & Best Practices

Package your expertise so it doesn't need re-explaining, then see what happens when real builders put Skills to work.

11:40 AM·40 MIN·Lecture
01

What a Skill Is

A reusable, filesystem-based resource: a folder of instructions, scripts, and reference material, organized roughly like an onboarding guide.

A prompt is conversation-level, for one task. A Skill loads on demand. A 14-skill journalism collection (AP style, source verification, FOIA templates) already exists, free to install.

02

What Actually Makes This Work

The Claude Code team's own account of building skills for production, sharper than the general advice.

  • The Gotchas section is the highest-signal part, built from real failures, not imagined ones.
  • Run the task once without the skill first, or you can't tell what it actually changed.
  • A skill fails to activate before it fails to execute. Vague descriptions kill routing.
03

A Real Investigation

A researcher replicated a real Virginia police-decertification investigation with Claude Code, under an hour.

Without the skill

  • Silently reformatted odd dates
  • Reported 80, undercounted

With the skill

  • Required provenance + a data-quality report
  • Reported 81, matched the published count

"Configuration matters as much as capability." The human remained essential throughout.

04

Common Failure Patterns

The confident-looking failure
Passes your test cases, fails on real input. Fix: test with messy real input.
The patch spiral
One-line fixes pile into contradictions. Fix: rebuild from what failed.
Installing skills from strangers
Shared skill repos have shipped credential-stealing malware. Fix: read before installing.

A skill you've never tested without is a skill you don't actually understand.
