Skills & Best Practices

Package your expertise so it doesn't need re-explaining, and follow a few habits Anthropic recommends.

11:50 AM·40 MIN·Lecture
01

What a Skill Is

A reusable, filesystem-based resource: a folder of instructions, scripts, and reference material, organized roughly like an onboarding guide.

A prompt is conversation-level, for one task. A Skill loads on demand, so the same guidance doesn't need repeating across every conversation.

02

What Actually Makes This Work

Most of Anthropic's own best-practices guidance comes down to giving Claude something concrete to check itself against.

  • Give Claude a way to verify its own work: tests, a build, a screenshot to compare.
  • Corrected the same issue twice? Clear the context and start over, more specifically.
  • Delegate research separately from implementation to keep your main conversation clean.
03

Vague vs. Specific

Claude can infer intent, but it can't read your mind.

Vague

  • "add tests for foo.py"
  • "validate email addresses"

Specific

  • "test the logged-out edge case, avoid mocks"
  • "validateEmail, with example cases, run tests after"
04

Common Failure Patterns

The kitchen sink session
Piling unrelated tasks into one conversation. Fix: one goal per session.
The trust-then-verify gap
Assuming code that runs is code that's correct. Fix: verify.

A Skill is stored expertise. The point is not re-explaining what you already know.
