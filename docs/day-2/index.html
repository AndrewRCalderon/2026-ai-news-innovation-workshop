Day 2: Iteration & Depth

Day 1 was experimentation. Day 2 is practice: prompting well, configuring Claude with CLAUDE.md and skills, planning before you build, and writing a spec instead of prompting straight to code. You'll spend the afternoon applying all of it to the project you started yesterday.

Learning Outcomes

  • Write and refine prompts that get you closer to what you actually want, and use Claude itself to help sharpen a weak prompt
  • Set up a CLAUDE.md file that keeps Claude consistent across a whole project instead of re-explaining context every session
  • Understand what a Skill is, how it differs from prompting, and when to reach for one
  • Use plan mode to align with Claude on an approach before it starts building
  • Apply a spec-driven checklist to write a clear spec before you start coding
  • Revisit your Day 1 project with all of the above and build further on it
