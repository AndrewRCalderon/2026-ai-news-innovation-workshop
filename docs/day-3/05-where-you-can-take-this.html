01

A Culture Coming Back

Newsrooms used to build and share tools constantly. Public code repositories from newsrooms fell from over 2,000 a year in 2016 to under 400 by 2024, an 80% collapse. The New York Times posted zero public repositories in 2024.*

What's changed since is exactly what you spent this week on. By early 2026, roughly 37% of new newsroom code repositories showed signs of AI-assisted building, a CLAUDE.md file, commits credited to an AI agent, growth that accelerated sharply starting around September 2025.* A journalist not being a programmer is becoming less of a wall than it used to be.

02

Named Roles, Right Now

These aren't hypothetical career paths. They're job titles that exist today:

Newsroom Architect, Politico
Bridges editorial and technical strategy, builds AI tools for investigative search, coordinates the newsroom's architecture roadmap.*
Computational Journalist, ProPublica
Built custom OCR software processing 7,000+ government files and a tool transcribing 2,000+ hours of radio into searchable timelines, before joining ProPublica's data team.*
Senior Editor, AI Innovation, CNN
Prototypes, tests, and deploys AI-powered tools and workflows directly with reporters.*

A recent industry survey of senior editors across 50+ countries ranked "coding and product development" the third most important AI use case for publishers, with 81% calling it important.*

03

You Don't Need to Be Hired to Do This

The clearest examples aren't engineering teams. They're individual reporters.

  • Andy Sullivan, a Reuters Washington correspondent with no programming background, has built 14 tools this way, including one that scans hundreds of daily Federal Register entries and flags what's newsworthy.*
  • One journalist built and now maintains a public library of 50+ Claude Code Skills for journalism tasks, FOIA, verification, data pipelines, entirely on his own.*
  • A researcher built a "tipsheet generator" Skill and tested it against 7 Pulitzer-winning investigations, extracting known leads from the original raw data blind. About half the leads it surfaced were genuinely useful starting points.*
04

A Realistic Read

Worth knowing before you oversell this to yourself: a randomized controlled trial found experienced open-source developers using AI coding tools were actually 19% slower, while believing they were 20% faster.* This isn't a straight line to being faster at everything, it's a specific new capability, most useful exactly where you have no other option: no budget, no engineer, no time to learn to code the traditional way.

Northwestern's journalism program ran an investigative AI challenge this year built entirely around this combination, Claude Code and Agent Skills, against a million-document corpus, open to freelancers and students, not just newsroom engineers.* That's the actual signal: this isn't a big-newsroom-only skill. It's already being treated as something worth teaching to exactly the kind of person in this room.
