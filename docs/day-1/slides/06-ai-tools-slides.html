AI Tools

New tools launch every week, and most of them will be irrelevant in a year. What doesn't go stale is knowing how to size one up fast.

2:40 PM·15 MIN·Lecture
01

Why This Matters

There's an AI tool for just about every task, and the list changes constantly. What's useful isn't memorizing today's lineup — it's a repeatable way to size up whatever's in front of you.

Check the Resources page for what's current — not this session.

02

Evaluating a New Tool

  • Does it solve a real problem?
  • What's the learning curve?
  • What's the cost?
  • Is there a free tier or trial?
  • Do I have the data it needs?
  • Is it actually better than what I already do?
Stick with tools you know until you have a clear reason to add a new one.
03

Familiarizing Yourself With a New Tool

  • Start with a task you already understand.
  • Skim the tool's own quickstart first.
  • Use a real example from your own work, not a toy one.
  • Note what surprised you — good or bad.
  • Get comfortable with 2–3 core capabilities before judging the rest.
The fastest way to know if a tool is worth learning is to bring it a real problem, not a demo.
