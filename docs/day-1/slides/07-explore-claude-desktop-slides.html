03

Getting Oriented

Chat
A normal conversation. No special file access unless you add one.
Cowork
Document/research-style work. Attach a workspace folder, step away, get a deliverable. Not a code editor.
Code
The real coding surface — editor, terminal, diff viewer, PR tooling. Where most of today happens.
  • Switch tabs from the tab bar near the message box.
  • Code tab: pick a Project folder to start.
  • Chat/Cowork: attach files via Connectors instead.
  • Customize panel manages connectors, skills, and plugins.
04

The Code Environment

Not a checklist — the real way to get good at this is to use it. Guardrails, then practice.

  • Be specific. Vague asks get vague results.
  • Use Plan mode for anything non-trivial.
  • Give it context instead of assuming it can guess.
  • Work in small steps.
  • Always read the diff. You're still responsible for the code.
  • Clarify, don't fight.
  • Treat surprises as information, not failure.
The fastest way to get good at this is to use it.
05

Connecting GitHub

Signs in through your browser — no tokens, no Git installed locally. Set it up now; you'll use it next session.

  • + next to the prompt box → Connectors → GitHub → sign in.
  • Claude can then read/write repos you have access to: files, commits, PRs.
  • Write actions ask for your approval first.

Different from the Code tab's own git, which needs Git and the GitHub CLI installed locally — the connector skips that step, which is why we're using it.

Same lesson as this morning's design process — no straight line from "describe it" to "done."
