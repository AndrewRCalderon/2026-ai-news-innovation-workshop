03

Quick Reference

  • Brainstorm or analyze: Claude, ChatGPT, Perplexity.
  • Write code: Claude Code or Copilot.
  • Analyze data: Claude or Jupyter + Claude.
  • Generate images: DALL-E or Midjourney.
  • Edit a transcript into audio: Descript.
  • Research with sources: Perplexity.
  • Automate workflows: Zapier or Make.
  • Build a web app: Claude Code + GitHub.
04

Evaluating a New Tool

  • Does it solve a real problem?
  • What's the learning curve?
  • What's the cost?
  • Is there a free tier or trial?
  • Do I have the data it needs?
  • Is it actually better than what I already do?
Stick with tools you know until you have a clear reason to add a new one.
