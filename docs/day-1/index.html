Day 1: State of the Art & Experimentation

Day 1 is orientation: where AI and journalism actually stand right now, what it can and can't do yet, and how to think about your own project idea. In the afternoon, you'll set up Claude Desktop, connect your GitHub workflow, and start experimenting with a workshop buddy.

Learning Outcomes

  • Explain what's actually changed in AI capability versus what's still hype, and where journalism specifically stands on adoption, trust, and job impact
  • Identify real, deployed AI use cases in and outside journalism, and recognize the pattern that separates a good AI problem from a bad one
  • Shape a project idea into a concrete problem statement, hypothesis, and goal
  • Evaluate a new AI tool with a repeatable method, instead of memorizing a lineup that goes stale in months
  • Set up and navigate Claude Desktop, with a first look at its code environment
  • Connect GitHub inside Claude Desktop and use the fork/commit/PR workflow you'll submit your work with
