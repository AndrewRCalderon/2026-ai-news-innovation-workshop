01

Why This Matters

You're about to enter a world where there's an AI tool for just about every task. The challenge isn't "are there tools?" — it's "which one should I use?" This section surveys the broader landscape so you can make informed choices. Your three required workshop tools get their own hands-on session, right after this one.

02

The Broader Landscape

Hundreds of AI tools exist. Here's what's worth knowing, by category.

Text & Writing

Claude
Anthropic. Best for analysis, ideation, writing. Free (limited) / Pro $20/mo.
ChatGPT
OpenAI. General-purpose, brainstorming. Free (limited) / Plus $20/mo / Pro $200/mo.
Gemini
Google. Research and writing, especially with Gmail/Docs. Free / Advanced (paid).
Perplexity
AI search with real-time web access. Free (limited) / Pro $20/mo.

Coding & Development

Claude Code
Reads your codebase, writes code, runs commands. Included with Claude Pro.
GitHub Copilot
Inline autocomplete as you type. Free (limited) / Pro $10/mo.
Cursor
VS Code with AI built in — tab completion, chat. Free / Pro $20/mo.
Replit
Write, run, and deploy in the browser — no local setup. Free / Boost $13/mo.

Data Analysis & Research

Claude (file upload)
Upload documents or datasets, ask questions about them. Included with Pro.
Jupyter + Claude
Interactive Python for data journalism and research. Free.
Airtable
Database with AI-assisted organization. Free / Pro $12/mo.

Images & Visuals

DALL-E
OpenAI. Text-to-image for illustrations, mockups. Pay per image, $0.02–$0.08.
Midjourney
Art-focused image generation. $10–120/mo.
Canva + Magic Design
Templates plus AI-assisted layout. Free / Pro $13/mo.

Audio & Video

ElevenLabs
Natural-sounding text-to-speech. Free (limited) / Starter $11/mo.
Descript
Edit video by editing the transcript; podcast/video production. Free (limited) / Pro $24/mo.
Synthesia
AI-avatar video from text — explainers, training. $30–60/mo.

Research & Learning

Perplexity
Answers with cited sources — research, fact-checking.
Zotero + AI plugins
Organize and summarize research papers. Free, open-source.
Google Scholar
Peer-reviewed paper search. Free.

Automation & Workflows

Make
Connect apps, automate repetitive tasks. Free (limited) / Pro $15/mo.
Zapier
No-code workflows between services. Free (limited) / Pro $19/mo.
03

Quick Reference

  • Brainstorm or analyze a topic: Claude, ChatGPT, or Perplexity.
  • Write code quickly: Claude Code (with project context) or Copilot (quick suggestions).
  • Analyze a dataset or paper: Claude (upload the file) or Jupyter + Claude.
  • Generate images for a story: DALL-E or Midjourney.
  • Turn a transcript into a podcast edit: Descript.
  • Research a topic with current sources: Perplexity.
  • Automate emails or organizing data: Zapier or Make.
  • Build a web app from scratch: Claude Code + GitHub.
04

Evaluating a New Tool

  • Does it solve a real problem I have — not just "this is cool"?
  • What's the learning curve?
  • What's the cost — free tier, subscription, usage-based?
  • Is there a free tier or trial to try before committing?
  • Do I have the data it needs?
  • Is it actually better than what I'm already doing?
Default rule: stick with tools you know until you have a clear reason to add a new one.
05

For This Workshop

Required

  • VS Code (free)
  • Claude Code (included with Claude Pro)
  • GitHub (free account)

Optional

  • Claude, for brainstorming and analysis
  • Perplexity, for research

You probably won't need OpenAI, Gemini, Midjourney, and the rest — though you're welcome to, if you have a reason.

Learn to use these three well. Everything else is optional.
