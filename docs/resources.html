Building & Deploying With Claude

Narrowed from a general AI tools survey to just what you'd reach for while coding a project with Claude and getting it live. Day 3's Recap & Open Questions names Vercel, Chainlit, Supabase, and Turso as platforms other students have reached for once a project outgrows a local prototype.

Coding Assistants

  • Claude Code — Reads your codebase, writes code, runs commands, right in your terminal or editor. Not on the free tier: Pro $17–20/mo, Max from $100/mo. This is what Day 2 introduces.
  • GitHub Copilot — Inline autocomplete plus chat, built into your editor. Free tier (2,000 completions + 50 chat requests/mo, no card needed) / Pro $10/mo.
  • Cursor — VS Code with AI built in — tab completion, chat, agent mode. Free Hobby tier (no card needed) / Pro $20/mo.
  • Replit — Write, run, and deploy in the browser, no local setup. Free tier is tight (about 40 minutes/day) / Core $25/mo ($20/mo billed annually).

Deploy & Persist Data

  • Vercel — Where most workshop projects actually deploy (this site included). Free Hobby tier needs no credit card but is personal-use only. Pro $20/seat/mo.
  • Chainlit — Open-source Python framework for building a chatbot-style interface fast. Free, no hosting included, pair it with Vercel or similar.
  • Supabase — Hosted Postgres database for a project that needs to persist data. Free tier (no card) auto-pauses after 7 days idle. Pro $25/mo per project.
  • Turso — Hosted SQLite, a lighter alternative to Supabase. Free tier (no card) is generous, unlikely to be hit in a 3-day project. Developer plan from $4.99/mo.
